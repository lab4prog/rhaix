# Зміни

## 1.0.0 — 2026-09-18

Перша стабільна версія. Мова `.rhx`, маршрути, дані, сесії, батарейки й
однофайловий деплой зафіксовані: до 2.0 вони не змінюватимуться так, щоб
зламати наявний застосунок.

### Мова й рендер

- Файл `.rhx`: frontmatter на Rhai плюс розмітка; логіка у відповідь не
  потрапляє.
- `{{ вираз }}` з **контекстним** екрануванням: текст, атрибут, перевірка схеми
  URL, `on*` як помилка компіляції, у `<script>` лише `json()`, у `<style>`
  інтерполяція заборонена.
- Директиви `@if` / `@else-if` / `@else` / `@for` / `@key` / `@class` /
  `@style` / `@attr` / `@html` / `@text` / `@oob`.
- Компоненти з props, `{...spread}`, слотами (звичайними та іменованими) й
  ізольованим scope. Невідомий тег і цикл залежностей — помилка **компіляції**.
- `<style>` і `<script>` компонента піднімаються в документ і дедуплікуються за
  хешем; `<style scoped>` звужує селектори до розмітки свого файлу.
- Помилка завжди в координатах `.rhx`: `pages/todo.rhx:7:26`, з кареткою,
  підказкою й ланцюжком компонентів.

### Маршрути й HTTP

- Маршрути зі структури тек: `pages/`, `partials/` → `/components/<name>`,
  `[id].rhx` → динамічні сегменти, `[...rest].rhx` → catch-all.
- Правило фрагмента: layout лише при звичайному заході, на `HX-Request` —
  сама розмітка сторінки.
- `middleware.rhx` перед кожним запитом; `page.layout` обирає обгортку.
- htmx і `rhaix.js` віддаються **з бінарника** — застосунок не залежить від CDN.

### Дані

- Дворівневий API: рідні запити (`db.query/one/exec`) і переносимий CRUD
  (`db.find/get/count/insert/update/delete`) зі словником операторів.
- `db.tx(|t| { … })` — транзакції на одному з'єднанні.
- Драйвери `sqlite` (за замовчуванням) і `postgres` за feature-флагом. Зміна
  драйвера — це зміна `rhaix.toml`, а не коду.
- Міграції `migrations/*.sql` застосовуються на старті, облік у
  `_rhaix_migrations`.

### Батарейки

- Сесії — підписаний cookie (HMAC-SHA256); CSRF проставляється сам і у форми, і
  на елементи з `hx-post`/`hx-delete`.
- `hash_password`/`verify_password` — Argon2id зі стандартом OWASP.
- `validate(значення, правила)`, `paginate(total, per, page)`.
- Завантаження файлів: `req.file/files/has_file`, `upload.save()` зі звіркою
  шляху.
- `mail.send(...)` — dev-режим у лог, SMTP за feature `mail`.
- `t("ключ")` + `locales/*.toml`; `markdown()` за feature `markdown` (сирий HTML
  екранується, схеми посилань перевіряються).
- `http.get/post/...` — синхронні виклики чужих API без винятків на збої.
- stdlib: дати, `slug`, `money`, `cut`, `url`, `json`, `uuid` та інше.

### Інструменти

- `rhaix dev` (живе перезавантаження), `serve`, `build` (один бінарник),
  `new`, `check` (`--json` для CI).
- Підсвітка `.rhx` для VS Code: `editors/vscode`.
- Доки українською та англійською, `llms.txt`, кухарська книга рецептів,
  посібник `GUIDE.md`.

### Вимірювання

- Ворота продуктивності: обчислення виразів 4.82 мс (межа 5), повний рендер
  1000 рядків 7.8 мс (межа 10).
- Порівняння з Astro на спільній базі: 1.1 / 6.8 / 16.4 мс проти 1.4 / 11.2 /
  25.6; 22 МБ пам'яті проти 154; старт 173 мс проти 721. Методика й
  застереження — `bench/README.md`.

### Свідомо не входить

Острівці, клієнтські компоненти й часткова гідратація — не гап, а рішення.
Scoped-слоти, `@key` для morph-свопів і `@transition` — v1.1. Драйвери MongoDB
й SurrealDB — трейт до них готовий, самих драйверів немає. Мовний сервер для
редактора — далі.
